# Bhairava AI

### Fraud Detector + Auto-Responder

A fraud prevention system I'm building for the **Razorpay AI Buildathon 2026**.

Bhairava AI aims to detect potentially fraudulent transactions, assess their risk, and automatically determine an appropriate response.

## Current Status

🚧 Day 0 — Project setup

## Planned

- Fraud risk scoring
- Fraud-specific feature engineering
- Model experimentation and evaluation
- Cost-sensitive threshold optimization
- Automated transaction response
- Explainable decisions
- REST API
- Audit logging

## Project Goal

Build a practical fraud decisioning system that balances fraud detection with the cost of blocking legitimate transactions.
